# Bonovista 카페24 상품 등록 스킬 (정본 / single source of truth)

> **정본 v3.7 — 2026-11-23.** v3.6(2026-11-21: 상품명 악센트 금지)에 태진 지시 두 가지를 더했다 — ① 핏·실루엣 줄 금지는 **컷소(티셔츠·스웻·저지·폴로)만**, 니트는 우븐 상의처럼 실측이 있을 때 쓴다(11-21 "오버 실루엣 같은 핏표기 금지는 티셔츠나 스웻같은 컷소만") ② 컷소·니트도 ⑦에 **실측을 감안한 국내 권장사이즈**를 쓴다(11-20 "권장사이즈는 써도 된다, 사이즈 실측을 감안해서") — §2 ⑤·⑦·부록 A 게이트(kind `cutsew` 신설). 11-22~23 계정 스킬에 따로 들어간 '원단 출처를 ~가 짠 주어+서술로 쓰지 않는다' 규칙도 §2·게이트에 합쳤다.
> 이 문서가 카페24 리스팅 규칙의 **유일한 정본**이다. 메모리·프로젝트 지침과 충돌하면 이 문서가 이긴다. **단, 이 문서(v3.7, 2026-11-23)보다 나중 날짜의 태진 지시는 그 지시가 우선하며, 같은 세션 안에 이 문서와 부록 A 게이트를 고쳐 반영한다.**
> **규칙을 새로 정하면 메모리에만 쓰지 말고 이 문서와 부록 A 게이트를 같이 고친다.** 메모리는 배치 기록·근거 보관용이다.
> 세션 시작 시 이 문서 첫 줄의 버전(v3 이상)을 확인해 보고 첫 줄에 적는다.
> **"자동화실행"·"리스팅 시작" = 오케스트레이터로.** 태진이 "자동화실행"(띄어 쓴 "자동화 실행" 포함, 2026-11-16 — 늘 '리스팅 정본 확인 후 모드 B 실행'으로 인식)이나 "리스팅 시작"(예전 문구 "리스팅스킬 정본 확인후 신규상품 모드b 자동화 시작" 포함)이라고 하면 이 스킬 단독으로 처리하지 않는다. `bonovista-new-arrivals`를 로드해 그 순서(세션 준비 → 대상 확정 → 이 스킬 모드 B → "완료" → 게이트 → 브랜드 이미지)로 묻지 않고 바로 실행한다. 이 스킬이 먼저 열렸다면 곧바로 오케스트레이터를 로드해 넘긴다.

# 공유 규칙 (모드 무관)

## 1. 상품명 형식

`[연도] 영문 브랜드명(대문자) made in 원산지 - 영문 간략 설명(소문자) [(사이즈)]`

- **연도 prefix**: 연식 판별이 쉬우면 맨 앞에 `80's` / `90's` / `00's`. 어려우면 생략. 태진이 연식을 알려 주면 그대로 따른다.
- 브랜드명 **대문자**, 구분 하이픈(-) 뒤 설명은 **소문자**. 콜라보·별주는 `A x B` / `A for B` / `A par B`처럼 **소문자 연결어**로 잇는다(예 `YEAH RIGHT!! x HACO!`, `SAGE DE CRET for EDIFICE`). 라벨이 대소문자를 섞어 쓰는 고유 표기(`MUSE de DEUXIEME CLASSE`)는 연결어만 소문자로 둔다.
- **악센트 금지 (2026-11-21 태진)**: 상품명에는 라틴 악센트·특수 글자(É·È·Ç·Ö·Ñ·ø 등)를 쓰지 않고 일반 영문자로 쓴다. 라벨·브랜드 사전이 `CHLOÉ`·`AGNÈS B.`·`COMME DES GARÇONS`·`HERMÈS`·`IÉNA`로 적어도 제목은 `CHLOE`·`AGNES B.`·`COMME DES GARCONS`·`HERMES`·`IENA`. 하이픈 뒤 설명도 같다(`piqué`→`pique`, `bouclé`→`boucle`, `appliqué`→`applique`, `vicuña`→`vicuna`, `ø`→`o`, `ß`→`ss`).
  - 이유: 손님이 `chloe`로 검색하면 `CHLOÉ` 상품이 안 걸리고, 목록 카드가 이름을 브랜드·품목으로 나눌 때 악센트 글자에서 끊긴다. 11-21 기존 상품 183개를 일반 글자로 정리했다.
  - 브랜드 사전 조회(`scripts/brand_lookup.py`)는 악센트를 무시하고 찾으므로 일반 글자 제목으로도 그대로 찾아진다. 설명 본문(① 첫 줄 등 한글 문장 속 브랜드 표기)은 이 규칙의 대상이 아니다.
  - 게이트가 FAIL로 잡고 일반 글자로 바꾼 제목을 함께 보여 준다.
- **`made in 원산지`는 브랜드명과 하이픈 사이**. **허용 원산지(소문자) 18개**: `italy` / `france` / `swiss` / `germany` / `sweden` / `japan` / `u.s.a` / `nepal` / `portugal` / `lithuania` / `scotland` / `england` / `hungary` / `spain` / `bulgaria` / `poland` / `romania` / `ireland`. 목록 외·불명이면 **`made in` 생략**. 영국권은 라벨 표기 그대로(`made in scotland`·`made in england`) — `u.k`·`britain`으로 묶지 않는다. 끝에 마침표 금지(`u.s.a.` X). (2026-09-10 13개국 확정, 09-23 17개국, 10-30 ireland 추가 18개국 — 태진 지시) 원산지 판정 기준은 §3-2.
- **China는 상품명·설명 어디에도 미기재.**
- `MA-1`·`M-65`·`G9` 같은 모델 표기를 하이픈 뒤에 쓸지는 태진 확인 전이다 — 게이트가 WARN으로 표시하니 보고 끝에 올린다. `t-shirt`는 `tee`로 쓴다.
- 하이픈 뒤 설명은 **간결하게**: 목표 **2~3단어**(최대 4). 아이템 + 핵심 디테일 하나둘만, 부수 수식어 제거.
  - 줄이기 예: `buckle strap leather ankle boots`→`buckle leather boots` / `cross stitch tweed cropped jacket`→`cross stitch cropped jacket` / `red pique polo`→`pique polo`
  - **줄일 때 소재를 먼저 지킨다**: 색상·공정 수식어(washed·raw 등)·일반 섬유를 먼저 덜어내고, **cashmere·alpaca·silk·linen**이 원제목에 있으면 새 제목에 반드시 남긴다. 예: `silk guardian lion print open collar shirt` → `silk lion print shirt`(O) / `lion print shirt`(X).
- 간략 설명 내 하이픈 생략(`cross-stitch`→`cross stitch`), 색상 묘사·앞 숫자 제거.
- **천연 소재 표기 (pure / blend)**: 아래 **천연 섬유**가 ⓐ **단일 100%면 소재명 앞에 `pure`**, ⓑ **혼용원단이면 소재명 뒤에 `blend`**로 간략 설명에 표기한다. 대상 섬유 — `linen`(린넨/마) · `wool`(울) · `cashmere`(캐시미어) · `silk`(실크) · `mohair`(모헤어) · `alpaca`(알파카) · `angora`(앙고라) · `camel`(카멜) · `hemp`(헴프/대마) · `ramie`(라미/모시) · `vicuna`(비쿠냐). 예: `pure cashmere sweater` / `pure linen shirt` / `linen blend shirt` / `silk blend dress` / `wool blend coat`. **코튼(cotton)은 너무 흔하므로 제외**(pure·blend 어느 쪽도 미표기). **합성·재생 섬유(폴리에스터·나일론·아크릴·레이온·큐프라 등)에도 쓰지 않는다.**
- 라벨에 네임 표기가 있으면 **알려진 브랜드가 아니어도 라벨 그대로 대문자**로 사용(태진이 확인한 표기가 우선 — 예 `Nanostudic`은 오자가 아니다).
- **브랜드 표기 통일(태진 지정)**: `Y'S` 단독 라벨은 제목에 **`Y'S YOHJI YAMAMOTO`**로 쓴다(2026-11-13). 예: `Y'S YOHJI YAMAMOTO made in japan - cupro print dress`. Y'S BIS·Y'S FOR MEN·Y'SACCS 같은 서브라인은 라벨 표기를 따른다.
- **무브랜드(네임 자체가 없음)**: 소문자 **제품 유형만** 쓴다. `vintage -` 같은 접두를 브랜드 자리에 넣지 않고(2026-07-20 사고), `made in`도 붙이지 않는다(2026-08-31). 예: `striped camisole`.
- **원단 밀 병기 (2026-09-02 태진)**: 로로피아나 원단택(`Ing. Loro Piana & C.`)이 붙은 상품은 라벨 브랜드 뒤에 `LORO PIANA FABRIC`을 병기한다. `[라벨 브랜드] LORO PIANA FABRIC - 간략설명`. 원단택의 `FABRIC MADE IN ITALY`는 제품 원산지가 아니므로 `made in italy`는 넣지 않는다. 다른 원단 밀(LUIGI BOTTO·BROADHEAD & GRAVES 등)은 병기하지 않는다(미지시) — 원단 밀을 브랜드 자리에 단독으로 쓰는 것은 금지.
- 예: `90's POLO RALPH LAUREN made in u.s.a - oxford shirt` / `MARNI made in italy - buckle leather boots (245)` / `LORO PIANA made in italy - pure cashmere knit` / `MARGARET HOWELL made in japan - linen blend jacket` / (허용 외: Vietnam·Turkey 등) `90's GAP - check flannel shirt` / (영국권) `MACKINTOSH made in scotland - rubberised cotton coat` / (무브랜드) `striped camisole`

### 1-1. 제목 끝 사이즈 괄호 — 하의 허리 인치·슈즈 mm
- **하의·스커트 (2026-08-16 개정, 09-23 범위 표기 확정)**: 제목 맨 끝에 허리 인치 `(N)`.
  - **실측만 쓴다. 라벨 표기 사이즈는 쓰지 않는다.** 환산 `인치 = round(허리 단면cm × 2 ÷ 2.54)`(half-up). 예: 단면 32→25 / 34→27 / 38→30 / 41→32 / 46→36.
  - 밴딩(실측이 범위)이면 **범위 표기** `(31-38)` — 각 끝을 같은 식으로 환산(2026-09-23 태진 "범위표기" 확정 때 적용한 형식). 예전에 물결표 `(26~32)`로 들어간 제목은 그대로 둔다(게이트는 둘을 같은 값으로 본다).
  - **밑위 보정 (2026-11-13 태진)**: 실측 밑위가 짧으면 환산값에서 권장 인치를 낮춘다 — **밑위 27cm 이하는 2인치, 27cm 초과~29cm 이하는 1인치**. 밴딩 범위는 양 끝을 똑같이 낮춘다. 예: 단면 41·밑위 27 → 32에서 (30) / 단면 41·밑위 28.5 → (31). 밑위 실측이 없는 하의·스커트는 보정하지 않는다. `items.json`의 `rise`(실측 밑위 cm)로 게이트가 검사한다.
  - 실측이 아직 없으면 모드 B 엑셀에서는 제목 끝에 **빈 `()` 자리표시자**를 남기고, 실측이 들어오면 별도 파일로 채운다(B-5 ③).
  - 이미 괄호값이 있는 제목(태진·직원이 넣은 숫자, `(free)`, `(~숫자)`)은 **덮지 않는다.** 실측 환산과 다르면 번호만 보고.
  - 라벨과 실측 환산이 크게 어긋나 실측 오입력이 의심되면(예 87925: 라벨 W67 vs 단면 38cm) 기재를 보류하고 보고한다.
  - 원피스·상하의 세트(파자마 등)는 대상 아님. 랩스커트는 과대 산출 주의.
- **슈즈 (2026-09-22 태진)**: 제목 끝에 mm `(230)`. 실측 mm가 있으면 실측값, 없으면 라벨 사이즈 환산값. 환산이 애매하면 넣지 않고 보고.

## 2. 제품 설명 형식

- **문체·톤(최우선)**: 옷을 깊이 아는 오너가 직접 쓴 글처럼, 태진 문체로 매끄럽게. AI식 어색함·번역투·기계적 나열·상투구 배제. 형식 규칙과 충돌하면 매끄러움 우선. 글쓰기 기준 `bonovista-writing`.
- **디테일은 정확·전문·사실적으로, 그리고 간결하게(핵심 문체 규칙)**: 색·문양·구조를 **정확한 용어로** 쓰되 **간결하게**(각 요소를 문장으로 늘이지 말고 명사·명사구로 짧게). **① 브랜드 히스토리만 한두 줄 매끄러운 문장으로 풀고, ②~⑥ 형태·구조·소재 정보는 서술적으로 길게 풀지 않는다.** 금지: ① 모호·일반적 뭉뚱그림과 AI식 상투구, ② 과잉 감성·수사('~가 그대로 느껴짐' 류 의인화·감탄), ③ **움직임·인상 동사**('흐르다·깔리다·지나가다·가로지르다·떨어지다/떨어뜨리다·늘어지다·물결지다' 류) — 문양·형태·핏 모두 사실·기성 용어로만. 세부는 `bonovista-writing`.
- **사진으로 자명한 것은 나열하지 않는다(핵심, 2026-08-21 태진)**: 포켓 개수·단추 개수·벨트 루프 개수·지퍼 여부·소매 길이·뒷트임 유무처럼 **사진을 보면 당연히 확인되는 항목을 세거나 열거하지 않는다.** 설명은 **사진으로 안 보이는 정보**(브랜드 헤리티지·소재·원산지·컨디션·라벨 문구)와 **그 옷을 특징짓는 소수의 디테일**(원단명·조직, 배색 위치, 프린트·자수·각인 문구, 특수 봉제, 탈착 구조, 가공, 안감 사양)에만 쓴다. **디테일 줄은 3개 안쪽**, 한 줄에 항목 4개 이상 이어 붙이면 그 자체가 나열이다.
  - 예(X): `차콜 그레이, 노치드 라펠, 싱글 브레스트 2버튼, 패치 포켓 2, 라펠 버튼홀, 백 노벤트`
  - 예(O): `차콜 그레이, 테일러드 노치드 라펠에 붙임 주머니를 단 캐주얼한 구성, 뒷트임 없는 등판`
  - 예(X, 과잉 감성): `…문양에서 짜는 사람의 손이 그대로 느껴짐`
  - 예(X, 움직임 은유): `연한 민트그린 바탕에 톤온톤 줄이 깔리고, 레인보우 밴드 두 줄이 가로로 지나감`
  - 예(X, 너무 서술적): `오트밀 멜란지 울로 낮고 둥근 크라운을 잡고 브림에는 스티치를 두 줄 넣어 마감`
  - 예(O, 간결·사실적): `낮고 둥근 크라운, 넓은 소프트 브림, 인디고 히코리 스웨트밴드에 붉은 실 체인스티치 로고` / `나비·셰브론·모자 쓴 인물 문양을 위사로 엮음`
- **품번·관리 코드 금지 (2026-08-21) / 공식 모델명 줄 예외 (2026-10-08)**: 케어라벨의 품번·스타일 넘버·로트 같은 관리 코드는 쓰지 않는다(판독 단계에서는 브랜드 특정·진위 확인용으로 계속 수집). 제품 정체성인 모델 라인 번호(LEVI'S `501`·`505`, `POLO CORDS`)는 본문에 남긴다. **PORTER처럼 공식 모델명·품번 체계가 뚜렷한 브랜드는 ① 바로 아래 `모델명 [시리즈/모델명] [공식 품번]` 단독 줄을 넣는다**(예 `모델명 HEAT TOTE BAG 703-07966`). 브랜드 공식 사이트로 확인된 것만, 미확정이면 줄을 만들지 않는다.
- **AI식 어색 구문 금지**: `~만 남은` / `~ 없이 ~만` 처럼 **없는 것(라벨·정보)을 부각하는 구문**을 쓰지 않는다. 예: `라벨 없이 손으로 짠 문양만 남은 프린지 숍`(X) → `손으로 짠 기하 문양 프린지 숍`(O).
- **'새긴·수놓은·찍은' 꾸밈절 금지 (2026-11-18 태진 — AI식 표현)**: `[내용]을 [위치]에 새긴 [제품]`처럼 정보를 형용사절로 쌓아 명사 앞에 붙이지 않는다. `새긴`·`새겨진`·`새김`·`수놓은`·`찍은`·`찍힌` 모두 금지(라벨에 한정하지 않는다).
  - 꾸밈절을 풀어 **디테일 줄에 `[위치] [내용] [방식]` 명사구**로 따로 쓴다. ① 줄에는 제품명만 남긴다.
  - 방식은 실제 이름으로: **각인**(가죽·금속) / **자수**(실) / **프린트**(인쇄) / **표기**(라벨에 인쇄·직조된 문자).
  - 원산지 문구는 꾸밈절에서 지우고 ② 줄 `made in`으로만 쓴다.
  - 예: `프레임 안쪽에 사바에 제조를 새긴 DUAL MAG사의 스퀘어 하프림 안경테`(X) → ① `DUAL MAG사의 스퀘어 하프림 안경테` / ④ `프레임 안쪽 사바에 제조 각인`(O) · `버클에 브랜드 로고를 새긴`(X) → `버클 브랜드 로고 각인`(O) · `가슴에 로고를 수놓은`(X) → `가슴 로고 자수`(O) · `넥라벨에 찍힌 SINCE 1946`(X) → `넥라벨 SINCE 1946 표기`(O).
  - 동사형 `~에 표기된`도 같은 구조이므로 피하고 명사형 `표기`로 끝낸다. 브랜드 사전 첫 줄 사실에 이 구조가 남아 있으면 그대로 옮기지 말고 풀어 쓴다(예: `투 라인을 새긴` → `투 라인 로고로 알려진`).
- **원단 출처(밀·회사)를 '~가 짠' 주어+서술로 쓰지 않는다**: 원단 생산사를 주어로 '짜다'를 쓰면 어색하다. **원단 출처는 명사구로 붙인다**(`[회사] [소재] 원단` 또는 `[회사]의 [소재] 원단`). 예: `Loro Piana & C.가 짠 캐시미어 원단으로 일본에서 만든 테일러드 코트`(X) → `Loro Piana & C. 캐시미어 원단으로 일본에서 만든 테일러드 코트`(O) / `Loro Piana & C.의 캐시미어 원단으로 일본에서 만든 테일러드 코트`(O). (소재↔아이템을 '~로 짠'으로 잇는 것도 니트·직조에만.)
- **외래어는 한국 업계 표기로 (2026-08-21)**: 일본 자료의 가타카나 음차를 옮기지 않는다. `ダメージ加工` → **데미지 가공**(다메지 X), `ヴィンテージ`→빈티지, `リブ`→립/골지, `ステッチ`→스티치, `フラップ`→플랩, `ダブル`→더블.
- **제작은 '만들다/제작'**: 제품 제작을 '짓다/지어 온'으로 쓰지 않는다. 소재를 아이템에 '~로 짠'으로 잇는 건 니트·직조에만.
- **사이즈 미포함(핵심)**: 설명에 실측 사이즈 블록·빈 템플릿·cm 수치를 넣지 않는다. ⑦ 표기 사이즈·국내 추천 줄만 남긴다.
- **'(추정)' 표기 금지**: 판독으로 파악되는 것은 **확정 표현**으로 쓴다. 정말 알 수 없는 항목은 **그 줄을 만들지 않는다**. 브랜드 히스토리는 '사실 검증 규칙'을 따른다.
- 머리말 없이 본문으로. **줄 앞 대시(`- `) 금지.** 서식(폰트·크기·색·정렬) 지정 금지.
- **개조식 종결**: 입니다/습니다 금지, 명사형 종결.
- **원산지 영문 made in**: ② 줄은 **반드시 영문 소문자 `made in [국가]` 그대로** 쓴다. `일본 생산`·`이탈리아산` 같은 한글 의역 금지(2026-08-31 사고). 허용 목록은 상품명과 동일. 목록 외·China·불명은 미기재.
- **항목 순서**: ① 브랜드 소개+제품 형태 → (모델명) → ② 원산지 → ③ 소재·원단 → ④ 디자인 특징 → ⑤ 핏·실루엣 → ⑥ 컨디션 → ⑦ 표기 사이즈 + 국내 추천(성별 포함). (항목은 순서일 뿐 기계적 칸 채우기가 아니다 — 문체 규칙 우선.)
- ① 브랜드+형태는 **하나의 매끄러운 명사구**: `[국적·특징] 브랜드 [브랜드명]의 [제품 형태]`. **'[브랜드명]은 ~ 브랜드, [제품]' 주어+서술 금지.** 브랜드 모르면 형태부터.
  - 예(O): `일본 도쿄 기반의 니트 전문 브랜드 CRICKET의 라운드넥 반팔 니트 톱`
  - 예(X): `CRICKET은 일본 도쿄 기반의 니트 전문 브랜드, 라운드넥 반팔 니트 톱`
- **설명 본문의 브랜드명은 영문/원어(로마자·한자·가나) 그대로** — **한글 음역만 금지**. 예: `디케이앤와이`(X)→`DKNY`(O). 일본 브랜드는 원어 그대로도 허용(`田中帽子店`).
- **개인 정보가 찍힌 라벨**: 전 소유자 실명·주소·이니셜이 보이면 설명에 옮기지 않는다(이니셜 자수는 `이니셜 자수`로만). 이미지 마스킹이 필요한 상품 번호는 보고 끝에 올린다(2026-08-20 L.L.Bean 사례).

### ① 첫 줄 브랜드 소개 — 헤리티지 한 겹 (2026-08-06 추가)
① 줄은 **브랜드가 무엇인지 한 겹 알려 주는 문장**이어야 한다. `[국적] 브랜드 [이름]의 [제품]`만 쓰면 정보가 0이다.

- **필수 원소 3개 중 최소 2개**를 명사구 안에 녹인다: **① 시작 연도·장소 ② 창업자 또는 모회사 ③ 그 브랜드를 그 브랜드로 만든 것**(대표 제품·기술·포지셔닝).
- **창립 표현은 '설립'으로**: '세우다/세운/세워' 대신 **'설립하다/설립해'**. ('문을 열어', '시작해'는 허용.)
  - 예(X): `일본의 여성복 브랜드 DAHL'IA의 깅엄 체크 타이트 스커트`
  - 예(O): `핸드메이드 가방과 리메이크 티셔츠에서 출발해 프릴과 자수 같은 손맛 나는 장식을 살려 온 일본 브랜드 DAHL'IA의 깅엄 체크 타이트 스커트`
  - 예(O): `1853년 샌프란시스코에서 시작해 1873년 리벳 보강 특허로 블루진을 세상에 내놓은 LEVI'S의 코듀로이 부츠컷 팬츠`
  - **예(이상적)**: `1880년 사이타마 가스카베에서 문을 열어 밀짚을 일곱 가닥으로 엮은 사나다를 감아 만드는 6대째 밀짚모자 공방 田中帽子店의 밀짚 캐스킷` / `1997년 도쿄에서 혼마 마사아키가 설립해 스커 모티프와 일본 생산으로 럭셔리 스트리트웨어를 만들어 온 MASTERMIND JAPAN의 오프숄더 롱슬리브 톱`
- **여전히 한 문장·한 명사구**. 목표 길이 50~90자.
- **서브 라인은 모체와의 관계를 밝힌다**: `MAX MARA가 1983년 연 캐주얼 라인 WEEKEND`, `UNITED ARROWS가 아오야마에 연 여성 최상위 라인 DRAWER`.
- 아래 줄과 **정보가 겹치지 않게** 한다.
- 오케스트레이터 완료 게이트 G4가 이 줄을 검사한다(영문 대문자·가나·한자 고유명 + '의'). 무브랜드 상품은 형태부터 쓴다.

#### 사실 검증 규칙 (어기면 오기 사고)
- **창립 연도·창업자·국적은 1차 출처(공식 사이트·위키·주요 매체)로만 쓴다.** 리셀 블로그·쇼핑몰 상세페이지가 유일 근거면 쓰지 않는다.
- **출처끼리 연도가 갈리면 숫자를 빼고 서술로 돌린다.** 예: YSL은 1961/1962가 갈려 `1960년대 초 파리에서`로.
- **이름이 유럽식이어도 국적을 단정하지 않는다.** `AUDREY AND JOHN WAD`는 도쿄 랜드워즈의 일본 브랜드, `LAISSÉ PASSÉ`·`crépuscule`도 일본 브랜드다. 동명 브랜드가 여럿이면 **특정 불가**로 두고 서사를 쓰지 않는다.
- **브랜드 히스토리가 없으면 '~라벨을 단' 표현을 쓰지 않고 `[브랜드]사의 [제품]` 형식으로 쓴다.** 라벨·각인에 사실이 더 있으면 ① 줄에 꾸밈절로 붙이지 말고 디테일 줄에 따로 쓴다: ① `DUAL MAG사의 스퀘어 하프림 안경테` / ④ `프레임 안쪽 사바에 제조 각인`.
- **브랜드 네임 자체가 없으면** '라벨 없이/문양만 남은' 식으로 없음을 드러내지 말고 있는 특징으로 서술한다.
- 조사 결과에 `confidence: low`가 붙은 항목은 첫 줄에 넣지 않는다.

#### 브랜드 판독 함정 (재발 사례에서 정리)
- **상세이미지 파일명은 브랜드 근거가 아니다** — 넥라벨·케어라벨·품번 체계로 반드시 교차확인(2026-08-12 ETMX `herill26awlook.jpg` 오신뢰 사고).
- **라벨이 없고 프린트에 짧은 단어가 크게 박혀 있으면 그 단어를 브랜드 후보로 먼저 검색**한다(2026-08-20 `POOL` 프린트 = THE POOL AOYAMA). 판독 서브에이전트에게 `brand_label`이 없으면 프린트·자수 문자열을 `brand_candidate`로 올리게 한다.

- **⑤ 핏·실루엣 — 품목별 (2026-09-09 확정, 08-29·09-14 범위 확정)**:
  - **하의(스커트·팬츠)**: 필수. 정성적으로.
  - **컷소**(티셔츠·스웻·폴로/피케·저지 톱): **실측이 있어도 ⑤를 쓰지 않는다.** 드롭숄더·박시·오버 같은 실루엣 표현 금지(2026-11-21 태진 — 핏 표기 금지는 컷소만).
  - **우븐 상의·니트(풀오버·카디건·볼레로)·아우터·원피스**: 실측(상품결제안내 `단면 사이즈`)이 있을 때만 그 수치를 참고해 쓰고, 없으면 생략. 이미지만으로 핏을 서술하지 않는다.
  - 어깨 실루엣은 옷걸이 사진으로 판단하지 않는다. **드롭숄더는 실측으로만** — 단면 어깨/가슴 비율이 정상 범위(0.75~0.82)를 확실히 넘을 때만(예 0.89) 쓴다. 실측이 없거나 애매하면 쓰지 않는다.
  - '넉넉한 레귤러핏' 같은 모순·모호 표현 금지. cm 수치 금지.
- **컨디션 단계**: `좋은 컨디션` / `미세한 사용감` / `부분 오염`(위치 명시). **'좋은 컨디션'과 결함 중복 금지.** **'누런/누렇게' 금지 → '얼룩'.** 얼룩은 담백하게('심한·짙은·눈에 띄는' 금지). 데미지 가공은 결함이 아니라 디자인으로 쓴다.
- **사이즈 판독(작성엔 미반영)**: 라벨 UK/EU/IT/FR은 국내(KR) 환산 기준으로 이해. 환산 가이드(여성): 44=UK6/EU34/IT38, 55=UK8/EU36/IT40, 66=UK10/EU38/IT42, 77=UK12/EU40/IT44, 88=UK14/EU42/IT46.
- **보이는 정보만**. 모르는 항목은 줄을 만들지 않음.

### ⑦ 표기 사이즈 / 국내 추천 줄 (설명에 유지)
- 라벨 표기 사이즈(S/M/L·숫자)가 있으면 `표기 사이즈 …` 줄로 기재 + 국내 추천.
- **남녀공용(유니섹스)은 '국내 남녀공용 X 추천' 금지** — `표기 사이즈 L, 유니섹스로 추천`.
- **이 줄에 실측 수치(cm)를 쓰지 않는다.** **하의는 표기 사이즈 줄 생략**(허리 인치는 제목 괄호로).
- **컷소·니트도 실측을 감안해 국내 권장사이즈를 쓴다**(2026-11-20 태진) — `표기 사이즈 맨즈 L, 국내 남성 100 추천`. 실측(단면 가슴·어깨·기장)으로 라벨 사이즈를 국내 기준에 맞춰 판단하고, 실측이 없으면 표기 사이즈만 쓴다. 컷소는 쉼표 뒤에도 핏·실루엣 표현(오버핏·박시 등)을 붙이지 않는다.
  - 예(O, 우븐 셔츠): `표기 사이즈 M, 국내 남성 95 추천` / 예(O, 여성): `표기 사이즈 38, 국내 여성 55 추천` / 예(O, 티셔츠): `표기 사이즈 L, 국내 남성 100 추천` / 예(X): `표기 사이즈 L, 오버핏 유니섹스로 추천`(컷소에 핏 표현) / 예(X): `표기 사이즈 L, 단면 어깨 55·가슴 55cm …`

### HTML 생성 규칙
- 설명 본문은 `<br>` 조인 금지, **각 줄을 `<div>…</div>`로**. 폰트·스타일 미지정.

BOTTOM_FIT = r"(핏|실루엣|스트레이트|와이드|테이퍼드|부츠컷|플레어|A라인|펜슬|스키니|레귤러|배기|머메이드|타이트|세미)"
BENIGN = r"(얼룩무늬|펀칭\s*구멍|구멍\s*(?:간격|장식)|벨트\s*구멍|아일렛|데미지)"
DEFECT = r"(얼룩|오염|구멍|올\s*풀|보풀|변색|손상|헤짐|해짐|찢|갈라짐|탈락|스크래치|까짐|벗겨짐|들뜸|크랙)"
KR_ORIGIN = (r"(일본|이탈리아|프랑스|스위스|독일|스웨덴|미국|네팔|포르투갈|리투아니아|스코틀랜드|영국|잉글랜드|"
             r"헝가리|스페인|불가리아|폴란드|루마니아)\s*(?:에서\s*)?(생산|제작|제조|산|제)(?![가-힣])")
MODEL_TOK = re.compile(r"\b[A-Z]{1,3}-?\d{1,3}[A-Z]?\b")   # MA-1·M-65·G9·N-3B 같은 모델 표기
YEAR = re.compile(r"^\d{2}['’]?s\s+")
SPECIAL = {"ø": "o", "Ø": "O", "ß": "ss", "ẞ": "SS", "æ": "ae", "Æ": "AE", "œ": "oe", "Œ": "OE",
           "ł": "l", "Ł": "L", "đ": "d", "Đ": "D", "ð": "d", "Ð": "D", "þ": "th", "Þ": "TH",
           "ı": "i", "ħ": "h", "Ħ": "H", "ŋ": "ng", "Ŋ": "NG"}

def plain(s):  # 악센트·특수 라틴 글자 → 일반 영문자 (2026-11-21 상품명 악센트 금지). 분해→부호 제거→특수 글자→재결합
    s = "".join(c for c in unicodedata.normalize("NFKD", s) if not unicodedata.combining(c))
    return unicodedata.normalize("NFC", "".join(SPECIAL.get(c, c) for c in s))

def accents(s):  # 라틴 계열 비ASCII 글자·결합 부호만(× ’ 한글 한자는 제외)
    return sorted({c for c in s if unicodedata.combining(c) or (not c.isascii() and c.isalpha()
                   and unicodedata.name(c, "").startswith(("LATIN", "FULLWIDTH LATIN")))})

def inch(cm):
    v = float(cm); return str(int(v * 2 / 2.54 + 0.5))          # half-up

def rise_cut(rise):
    # 밑위 보정(2026-11-13 태진): 27cm 이하 2인치, 27cm 초과~29cm 이하 1인치 낮춤
    if rise in (None, "", "-"): return 0
    r = float(rise); return 2 if r <= 27 else 1 if r <= 29 else 0

def expect_waist(w, rise=None):
    w = str(w).replace("~", "-").replace(" ", ""); k = rise_cut(rise)
    if "-" in w:
        a, b = w.split("-", 1); return f"{int(inch(a)) - k}-{int(inch(b)) - k}"
    return str(int(inch(w)) - k)

def check_item(it, res):
    code, name = it["code"], (it.get("name") or "").strip()
    lines = [l.strip() for l in it.get("lines", []) if l and l.strip()]
    kind, text = it.get("kind", ""), " ".join(lines)
    F = lambda m: res.append(("FAIL", code, m)); W = lambda m: res.append(("WARN", code, m))
    low = name.lower()
    # ── 상품명 ──
    if re.match(r"(?i)^vintage\s*-", name): F("상품명 'vintage -' 접두 금지")
    if "china" in low: F("상품명에 China")
    if re.search(r"[가-힣]", name): F("상품명에 한글(직원 메모 잔존 의심)")
    acc = accents(name)
    if acc: F(f"상품명 악센트 글자 {''.join(acc)} — 일반 글자로: {plain(name)}")
    for c in re.findall(r"made in ([a-z.\- ]+?)(?= -|$| \()", low):
        c = c.strip()
        if c.endswith("."): F(f"made in 끝 마침표 금지: {c}")
        elif c not in ALLOWED: F(f"허용목록 밖 원산지: made in {c}")
    if re.search(r"(?i)made in", name) and not re.search(r"made in", name): F("made in은 소문자")
    m = re.search(r"\s\(([^()]*)\)$", name)
    paren = m.group(1) if m else None
    core = name[:m.start()] if m else name
    if " - " in core:
        left, right = core.split(" - ", 1)
        rest = MODEL_TOK.sub("", right)
        if MODEL_TOK.search(right): W(f"하이픈 뒤 모델 표기({MODEL_TOK.findall(right)}) — 대문자·하이픈 허용 여부 태진 확인 사항")
        if re.search(r"[A-Z]", rest): F(f"하이픈 뒤 설명은 소문자: {right}")
        if re.search(r"\w-\w", rest): F("하이픈 뒤 설명 안 하이픈 생략(t-shirt → tee)")
        if len(right.split()) > 4: F(f"하이픈 뒤 설명 {len(right.split())}단어(최대 4)")
        brand = re.sub(r"\s+made in .*$", "", YEAR.sub("", left))
        for tok in brand.split():
            t = unicodedata.normalize("NFKC", tok)
            if re.fullmatch(r"[a-z][a-z'’.]*", t) and t not in CONNECT: F(f"브랜드 대문자 표기: {tok}")
    else:
        if "made in" in low: F("무브랜드 상품명에 made in 금지(제품 유형만)")
        if re.search(r"[A-Z]", core): W("무브랜드 상품명에 대문자 — 브랜드면 ' - ' 형식으로")
    # 사이즈 괄호
    if kind == "bottom":
        if it.get("waist"):
            exp = expect_waist(it["waist"], it.get("rise"))
            if paren is None or paren == "": F(f"허리 인치 누락: ({exp}) 필요")
            elif paren.lower() != "free" and not paren.startswith("~") and paren.replace("~", "-") != exp:
                W(f"허리 인치 ({paren}) ≠ 실측 환산 ({exp}) — 라벨값이 이미 있으면 덮지 말고 보고")
        elif paren is None: W("허리 인치 대기(실측 없음) — 제목 끝 () 자리표시자 권장")
    elif kind == "shoes":
        if it.get("shoe_mm"):
            if paren != str(int(it["shoe_mm"])): F(f"슈즈 mm 표기 필요: ({int(it['shoe_mm'])})")
        elif paren is None: W("슈즈 mm 대기(실측·라벨 환산 없음)")
    elif paren and re.fullmatch(r"[\d\-~]+", paren): W(f"하의·슈즈 외 상품명 끝 숫자 괄호({paren})")
    # 천연 섬유 pure / blend
    for kr, en in FIBERS:
        if re.search(kr + r"\s*100\s*%", text) and not ("pure" in low and en in low):
            F(f"{en} 100% → 상품명 'pure {en}' 필요")
        elif re.search(kr + r"\s*\d{1,2}\s*%", text):
            if en not in low: W(f"{en} 혼용 → 상품명 '{en} blend' 검토")
            elif f"{en} blend" not in low: F(f"{en} 혼용원단 → 상품명은 '{en} blend'")
    if re.search(r"pure\s+" + NOFIBER + r"|" + NOFIBER + r"\s+blend", low): F("코튼·합성섬유에 pure/blend 금지")
    # ── 설명 ──
    if len(lines) < 3: W(f"설명 {len(lines)}줄")
    for i, ln in enumerate(lines):
        tag = f"{i+1}줄"
        if ln.startswith("-"): F(f"{tag} 줄 앞 대시")
        if "<" in ln or "style=" in ln: F(f"{tag} HTML·인라인 스타일")
        if re.search(r"(입니다|습니다|합니다)", ln): F(f"{tag} 정중체 종결")
        if ln.count(",") >= 4: W(f"{tag} 한 줄 항목 과다(쉼표 {ln.count(',')})")
        if re.search(r"모델명", ln) and not ln.startswith("모델명 "): F(f"{tag} 모델명은 '모델명 [시리즈] [공식 품번]' 단독 줄만")
        if i == 0:
            if re.search(r"(년|에서|가|이)\s*(세우다|세운|세워|세웠)", ln): F("① 창립은 '설립'으로")
            if re.search(r"^[^,]{1,40}(은|는)\s[^,]{0,40}브랜드\s*,", ln): F("① 주어+서술형 금지 — 하나의 명사구로")
    if re.search(r"혼방", text): F("'혼방' → '혼용원단'")
    if re.search(r"(?<![가-힣])면\s*(?:\d|소재|혼용)", text): F("'면' → '코튼'")
    if re.search(r"(?i)china|중국", text): F("설명에 China/중국")
    for mm in (m2 for l in lines for m2 in re.finditer(r"(?i)made in ([a-z.]+(?: [a-z.]+)?)", l)):
        seg, c = mm.group(0), mm.group(1).lower().strip()
        if seg != seg.lower(): F(f"설명 made in은 영문 소문자: {seg}")
        if c.endswith(".") and c.rstrip(".") in ALLOWED: F(f"설명 made in 끝 마침표 금지: {c}")
        elif c not in ALLOWED: F(f"설명 허용목록 밖 made in {c}")
    if re.search(KR_ORIGIN, " ".join(lines[1:])): F("원산지 한글 의역 — 'made in [국가]' 영문 소문자로")
    if "(추정)" in text: F("'(추정)' 금지 — 확정 표현 또는 줄 생략")
    if re.search(r"누런|누렇", text): F("'누런' → '얼룩'")
    if "다메지" in text: F("'다메지' → '데미지'")
    if re.search(r"\d+(\.\d+)?\s*cm", text) or "단면 사이즈" in text: F("설명에 cm 수치·사이즈 블록")
    enum = re.findall(r"(?:포켓|주머니|버튼|단추|벨트 루프|루프|지퍼|플리츠|탭)\s*\d{1,2}(?![\d.])(?!\s*(?:인치|%|년|s|mm|cm|’|'))", text)
    enum += re.findall(r"\d+\s*(?:버튼|단추)(?!홀)", text)
    if [e for e in enum if not re.match(r"^(?:505|501|45)", e)]: F(f"자명한 개수 나열: {enum[:3]}")
    if re.search(r"(?i)(품번|품\s번|스타일\s*넘버|article\s*no|style\s*no)", text): F("품번·관리 코드 기재 금지")
    if re.search(r"라벨을 단", text): F("'~라벨을 단' 금지 — '[브랜드]사의'")
    if re.search(r"(새긴|새겨|새김|수놓은|수놓아|찍은|찍힌)", text): F("'~을 ~에 새긴/수놓은/찍은' 꾸밈절 금지 — '[위치] [내용] 각인·자수·프린트·표기' 명사구로")
    if re.search(r"[A-Za-z.&)]\s*(?:가|이)\s*짠", text): F("원단 출처를 '~가 짠' 주어+서술로 쓰지 않는다 — '[회사]의 [소재] 원단' 명사구로")
    if re.search(r"만 남은|없이 [^,]{1,20}만 ", text): F("없는 것을 부각하는 구문(~만 남은/없이 ~만)")
    if re.search(r"(흐르|흘러|깔리|깔린|지나가|가로지르|떨어지|떨어뜨|늘어지|늘어진|물결지|물결치)", text): F("움직임·인상 동사")
    if re.search(r"느껴짐|느껴지", text): F("과잉 감성('~가 느껴짐')")
    if re.search(r"지어 온|지어온", text): W("제품 제작은 '짓다' 대신 '만들다/제작'")
    defects = [l for l in lines if re.search(DEFECT, re.sub(BENIGN, "", l)) and "가공" not in l]
    if "좋은 컨디션" in text and defects: F("'좋은 컨디션'과 결함 병기")
    if re.search(r"(심한|짙은|눈에 띄는)\s*\S{0,6}\s*(얼룩|오염)", text): F("얼룩 강조 표현")
    if re.search(r"넉넉한 레귤러", text): F("'넉넉한 레귤러핏' 류 모순")
    if re.search(r"국내 남녀공용", text): F("유니섹스는 '유니섹스로 추천'만")
    if "드롭숄더" in text and not it.get("drop_ok"): F("드롭숄더는 실측 비율 근거(drop_ok)가 있을 때만")
    scan = " ".join(l for l in lines[1:] if not re.search(r"(프린트|그래픽|인물|문양|자수)", l))
    if kind == "cutsew":   # 2026-11-21 태진: 핏 표기 금지는 컷소만 / 11-20: 권장사이즈는 허용
        if re.search(FIT, scan): F("컷소(티셔츠·스웻·저지·폴로)는 ⑤ 핏·실루엣 줄 금지")
        for l in lines:
            if l.startswith("표기 사이즈") and re.search(FIT, l): F("컷소 ⑦에 핏·실루엣 표현 금지 — 권장사이즈만")
    elif kind in ("top", "knit", "outer", "dress") and not it.get("measured"):
        if re.search(FIT, scan): F("실측 없는 상의류에 핏 서술 — ⑤ 생략")
    elif kind == "bottom":
        if not re.search(BOTTOM_FIT, " ".join(lines[1:])): F("하의 ⑤ 핏 줄 필수")
        if any(l.startswith("표기 사이즈") for l in lines): F("하의는 ⑦ 표기 사이즈 줄 생략")
    # ① 첫 줄 브랜드
    if " - " in core and lines:
        brand = re.sub(r"\s+made in .*$", "", YEAR.sub("", core.split(" - ", 1)[0])).strip()
        key = plain(unicodedata.normalize("NFKC", brand)).casefold()      # 제목은 일반 글자, 첫 줄은 악센트 표기여도 같은 브랜드로 본다
        first = plain(unicodedata.normalize("NFKC", lines[0])).casefold()
        if key and key not in first and key.split()[0] not in first: W(f"① 첫 줄에 제목 브랜드({brand}) 없음")

def check_excel(path, mode, items, res):
    import openpyxl
    ws = openpyxl.load_workbook(path).active
    rows = list(ws.iter_rows(values_only=True))
    head = [str(h).strip() if h else "" for h in rows[0]]
    F = lambda m: res.append(("FAIL", "엑셀", m))
    allow = {"desc": [{"상품코드", "서비스문의/안내"}, {"상품코드", "상품명", "서비스문의/안내"}],
             "title": [{"상품코드", "상품명"}], "waist": [{"상품코드", "상품명", "상품결제안내"}]}[mode]
    if set(head) not in allow: F(f"컬럼 구성 {head} — 허용: {allow}")
    if "상세설명" in " ".join(head) or "이미지" in " ".join(head): F("상세설명·이미지 컬럼 포함 금지")
    if mode == "desc" and "상품결제안내" in head: F("설명 파일에 상품결제안내(사이즈 칸) 포함")
    codes = []
    for r in rows[1:]:
        d = dict(zip(head, r)); codes.append(d.get("상품코드"))
        for h in head:
            if d.get(h) in (None, ""): F(f"{d.get('상품코드')} 빈칸 '{h}' — 빈칸은 기존값 삭제")
        s = str(d.get("서비스문의/안내") or "")
        if mode == "desc":
            if "단면 사이즈" in s: F(f"{d.get('상품코드')} 설명 칸에 사이즈 블록")
            if not re.fullmatch(r"(<div>[^<>]+</div>)+", s): F(f"{d.get('상품코드')} 설명 HTML은 <div>줄</div>만")
        if mode == "waist":
            p = str(d.get("상품결제안내") or "")
            if "단면 사이즈" not in p or "(inch)" in p or not re.search(r"\([\d\-~]+ inch\)", p):
                F(f"{d.get('상품코드')} 상품결제안내는 라이브 값에서 (inch)만 (N inch)로 치환")
    if items:
        want = {i["code"] for i in items}
        if set(codes) != want: F(f"엑셀 상품코드와 카피 목록 불일치: {sorted(set(codes) ^ want)[:5]}")
        names = {i["code"]: i["name"] for i in items}
        if "상품명" in head:
            for r in rows[1:]:
                d = dict(zip(head, r))
                if names.get(d["상품코드"]) and names[d["상품코드"]] != d["상품명"]: F(f"{d['상품코드']} 엑셀 상품명≠카피")

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("items"); ap.add_argument("--excel"); ap.add_argument("--mode", default="desc")
    ap.add_argument("--strict", action="store_true")
    a = ap.parse_args()
    items = json.load(open(a.items, encoding="utf-8"))
    res = []
    for it in items: check_item(it, res)
    from collections import Counter
    for t, n in Counter(i["name"] for i in items).items():
        if n > 1: res.append(("FAIL", "배치", f"제목 중복 {n}건: {t}"))
    for t, n in Counter((i.get("lines") or [""])[0] for i in items).items():
        if n > 1 and t: res.append(("WARN", "배치", f"① 첫 줄 중복 {n}건: {t[:30]}"))
    if a.excel: check_excel(a.excel, a.mode, items, res)
    fails = [r for r in res if r[0] == "FAIL"]; warns = [r for r in res if r[0] == "WARN"]
    for r in fails + warns: print(f"[{r[0]}] {r[1]} {r[2]}")
    bad = fails or (a.strict and warns)
    print(f"{'❌ FAIL' if bad else '✅ PASS'} — {len(items)}건 / FAIL {len(fails)} / WARN {len(warns)}")
    sys.exit(1 if bad else 0)

if __name__ == "__main__":
    main()
