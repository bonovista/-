# 비용 장부 안내 · 쓴 돈 기록 시연 두 편

온라인 비용 장부 사용 안내(cost.bonovista.com 직원용)의 앱 캡처 두 장(금액부터 용도까지, 결제부터 사진까지)을 Stageshow 시연 두 편으로 다시 만들었습니다.

- 시안 페이지: 비공개 아티팩트 '비용 장부 안내 시안'
- 정지 화면(포스터): `poster-expense.png`, `poster-payment.png`

두 편 모두 폰 한 대를 위에서 고정하고 아래는 화면 끝에서 자릅니다. 화면에 보이면 한 번 재생되고, 끝난 상태가 그대로 남습니다. 캡션 옆의 '다시 보기'를 누르면 처음부터 다시 재생됩니다. 움직임 줄이기 설정을 켠 기기에서는 마지막 상태가 정지 화면으로 보입니다.

## 1편 · 금액부터 품목까지 ('돈을 썼을 때' 옆)

1. 금액 칸에 30,000이 입력됩니다.
2. 거래처 단추 '국제세탁'을 누르면 거래처 칸이 채워집니다.
3. 0.3초 뒤 종류 '세탁'이 같이 선택되고, 세탁 품목 줄이 열립니다.
4. '가죽다림'을 두 번 누르면 '가죽다림 1', '가죽다림 2'가 되고 옆에 − 단추가 생깁니다.

## 2편 · 결제부터 증빙까지 ('영수증과 외상' 옆)

1. 결제에서 '현금'을 누르면 "현금으로 낼 때는 지출증빙용 현금영수증으로 요청하세요." 안내와 사업자번호가 열리고, 같은 순간 증빙의 '카드전표'가 흐려집니다.
2. '복사'를 누르면 단추가 '복사됨'으로 바뀝니다.
3. 증빙에서 '지출증빙 현금영수증'을 고릅니다.

사업자번호 123-45-67890은 안내 페이지의 예시 번호를 그대로 썼습니다.

## 파일

| 경로 | 내용 |
|---|---|
| `expense/` | 1편 컴포넌트(React), 두 편이 같이 쓰는 스타일, Pretendard 부분 글꼴 |
| `payment/` | 2편 컴포넌트와 2편에만 쓰는 스타일 |
| `embed/` | 안내 페이지에 넣을 단일 스크립트·스타일로 묶는 Vite 설정 |
| `compose.py` | 안내 페이지 사본에 두 시연을 끼워 넣는 스크립트 |

## 다시 빌드하기

`.claude/skills/stageshow`를 작업용 폴더로 복사한 뒤 그 안에서:

```sh
npm install
cp -r <repo>/bv-ledger-demo/expense examples/bv-expense
cp -r <repo>/bv-ledger-demo/payment examples/bv-payment
cp -r <repo>/bv-ledger-demo/embed embed
node node_modules/vite/bin/vite.js build --config embed/vite.config.ts   # embed/dist/ 생성
python3 <repo>/bv-ledger-demo/compose.py <안내 원본.html> embed/dist <글꼴 폴더> <결과.html>
```

글꼴 폴더에는 `P-Regular.woff2`, `P-Medium.woff2`, `P-SemiBold.woff2`가 있어야 합니다. `expense/`에 들어 있는 부분 글꼴을 쓰면 됩니다. 안내 문구를 바꾸면 Pretendard 원본에서 다시 잘라야 합니다.

미리보기 서버는 `node node_modules/vite/bin/vite.js playground --config playground/vite.config.ts`, 화면 확인은 `CHROME_PATH=<chromium> node scripts/film.mjs "http://127.0.0.1:<port>/?capture=bv-payment" --select '#example' --gate`입니다.

## 점검 기록 (REHEARSAL)

- **참고한 기준 예시:** `phone-touch`(폰 고정 구도, 터치 커서), `form-error`(한 번 재생, 포스터가 결과 화면, 단추가 제자리에서 상태를 바꿈).
- **바꾼 것:** 안내 페이지의 색(종이색, 잉크, 번트 시에나)과 Pretendard, 선택 단추는 잉크 채움, 모서리 없음. 폰 테두리는 안내 페이지의 가는 선과 맞추려고 `outline`을 썼습니다. 이야기 밖의 칸(1편의 용도·결제·증빙, 2편의 품목·용도·날짜·메모·사진)은 회색 막대로 두었습니다.
- **통과:** `film.mjs --gate` 결과 두 편 모두 `rehearsal passed`. 1편은 넓은 화면, 2편은 572px과 390px 두 너비에서 확인했습니다. 시작 화면과 정지 화면도 두 너비 모두 지적이 없습니다.
- **남은 지적과 판단:**
  - 0.07초의 글자 폭 점프: 미리보기 서버에서 글꼴이 늦게 불러와져 생긴 것. 안내 페이지에서는 글꼴이 페이지 안에 들어 있어 거의 생기지 않습니다.
  - 금액 숫자가 입력될 때 한 자리씩 왼쪽으로 밀리는 것: 오른쪽 정렬 입력칸의 실제 동작이라 `data-snap`으로 표시했습니다.
- **확인하지 못한 것:**
  - 1편: 품목 단추가 종류에 따라 바뀌는지(세탁을 고르기 전에는 품목 줄이 없는지). 기존 기록(물보라 '지퍼', 중앙단추 '단추')을 보고 추정했습니다.
  - 1편: 거래처 칸의 빈 상태 문구('거래처 이름')는 실제 앱 문구가 아닐 수 있습니다.
  - 2편: 현금을 고르면 카드전표가 흐려지는 것. 원래 캡처에서 현금 선택 상태일 때 카드전표가 회색이었던 것을 보고 추정했습니다.
  - 2편: 복사 뒤 단추 문구('복사됨')와 그 문구가 계속 남는지는 실제 앱과 다를 수 있습니다.
  - 2편: 결제를 고르기 전의 증빙 배치. 현금 선택 상태의 캡처 배치를 그대로 썼습니다.
  - 실제 아이폰 사파리에서의 재생 속도와 스크롤 중 동작.
  - 별도 리뷰어의 검토(review.md)는 하지 않았습니다.
